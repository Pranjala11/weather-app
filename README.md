# 🌤️ Weather App

A full-stack weather app built with the MERN stack.

## 🔴 Live Demo
weather-app-six-phi-24.vercel.app
https://weather-app-six-phi-24.vercel.app/

## 🛠️ Tech Stack
- **Frontend:** React + Vite
- **Backend:** Node.js + Express
- **Database:** MongoDB (Railway)
- **API:** OpenWeatherMap

## ✨ Features
- Search weather by city
- GPS location detection
- Dynamic backgrounds based on weather
- Search history
- Mobile responsive

## 🚀 Setup
```bash
# Backend
cd server
npm install
npm run dev

# Frontend  
cd client
npm install
npm run dev
```
